我们希望每个人都能使用根芽。我们的目标是达到《网页内容无障碍指南》（WCAG）2.2 的 AA 级。目前还没有完全做到，也还没有请外部机构审核过。这里如实说明现状。

1. 目前已经做到的

  • 按钮和链接都是标准控件，可以用键盘或开关设备操作，并有清晰的焦点框。
  • 只有图标的按钮都带有读屏可读的中英文标签。
  • 文字会跟随浏览器缩放和字号设置。
  • 如果你的设备开启了“减少动态效果”，我们会关闭动画。
  • 语音和视频通话都会实时显示你和角色说的话的字幕。
  • 语音消息不是必须的，你随时可以改为打字。

2. 已知问题

  • 角色发来的照片和短片暂时还没有文字描述。
  • 角色发来的语音消息不一定都带文字稿。
  • 部分弹出面板打开时还不能把键盘焦点限制在面板内，可以按 Esc 关闭。
  • 消息菜单需要长按或右键打开（键盘可用 Shift+F10），暂时没有可见的按钮。
  • 视频通话中的角色动画仅作装饰，没有口述影像；对话内容以字幕为准。
  • 部分浅色的辅助文字可能达不到建议的颜色对比度，我们还没有逐页检测。
  • 我们还没有在高倍缩放下、也没有用所有读屏软件测试过每个页面。

我们正在逐一解决这些问题，修好一项就会更新这一页。

3. 本网站

本网站使用标准 HTML，带有标题结构、页面区域标记和“跳到正文”链接，可以用键盘操作，会跟随你的浅色或深色模式以及减少动态效果设置，每张图片都有文字描述。

4. 告诉我们哪里不好用

如果有什么地方很难用或无法使用，或者你需要其他格式的信息，请发邮件至 support@raicita.app，告诉我们是哪个页面、你想做什么。会有真人回复你。

如果你对我们的处理不满意，可以联系英国平等咨询与支持服务（EASS）。
